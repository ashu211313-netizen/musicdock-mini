# プライバシーポリシー

更新日: 2026年10月23日 / 対象: MusicDock Mini 1.1.0

本拡張機能は https://music.youtube.com/ のトップレベルページだけで動作します。表示中の曲名・アーティスト・ジャケットURL、メディアの再生状態・時間・音量を読み、小窓に表示します。利用者の操作に応じ、ページの再生ボタンまたはメディア要素を操作します。

アカウント、Cookie、パスワード、履歴を取得しません。分析・広告SDK、独自サーバーへの通信、データの販売・第三者提供はありません。曲情報・設定を永続保存しません。

ジャケットはYouTube Musicページがすでに読み込んだ画像をCanvasへ描画します。画素の読み戻し・保存・送信は行いません。画像URLはHTTPSの ytimg.com / googleusercontent.com / ggpht.com とそれらのサブドメインだけを許可します。拡張機能が画像を追加取得することはありません。元ページの画像取得やYouTube Music自体のデータ処理にはGoogleのポリシーが適用されます。

紹介サイトに分析・Cookie・ログイン機能はありません。GitHub Pagesに公開された場合は、配信サービスがリクエスト情報を処理する場合があります。

専用の拡張機能権限や全サイトアクセスは要求しません。コンテンツスクリプトの対象ホストだけがmusic.youtube.comに限定されています。

問い合わせ先は公開時のGitHubリポジトリのIssuesを使用する予定です。現時点でリポジトリおよび問い合わせURLは未設定です。ストア申請前に公開先・連絡先を確定する必要があります。
