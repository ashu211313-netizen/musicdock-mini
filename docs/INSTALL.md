# MusicDock Mini 1.1.1 導入ガイド

Windows 10 / 11、最新のデスクトップ版Google ChromeまたはMicrosoft Edgeを使用してください。

1. musicdock-mini-1.1.1.zipを「すべて展開」します。
2. Chrome: chrome://extensions / Edge: edge://extensions をアドレスバーに入力。
3. 開発者モードをオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」または「展開して読み込み」で、manifest.jsonが入ったフォルダを選択。
5. https://music.youtube.com/ を開きます。既存のタブは更新します。
6. 曲を選択し、右下の「♫ MINI を開く」をクリックします。

小窓のタイトルバーをドラッグして移動、端をドラッグしてサイズ変更できます。OS・ブラウザが定める最小サイズ等の制約があります。「↗」またはブラウザ標準の戻るボタンで元タブに戻れます。「×」で閉じ、元タブの「♫ MINI」から再度開けます。

プレイヤーの背景にフォーカスがあるとき: Space = 再生/一時停止、左右矢印 = 5秒シーク、Escape = 閉じる。入力・ボタン上では標準のキーボード操作を優先します。

元のタブは開いたままにしてください。タブの終了・更新で小窓も閉じます。ウィンドウ位置・サイズの記憶はブラウザに委ねており、拡張機能では保存しません。

起動不可: 最新の対応ブラウザ、HTTPS、PiPの管理者設定を確認し、ボタンを直接クリックしてください。操作不可: 元タブの曲選択・再生エラーを確認。YouTube MusicのDOM変更は更新対応が必要です。広告・ライブ等ではシークできないことがあります。

更新: 新版ZIPを別フォルダで展開するか現在のフォルダに置き換え、拡張機能管理画面で「更新/再読み込み」、YouTube Musicタブを更新。
削除: 拡張機能管理画面の「削除」。展開フォルダも不要なら削除できます。

ストア未公開のプレビュー版です。実サービス上の互換性確認は未完了です。Google / YouTubeの公式アプリではありません。
