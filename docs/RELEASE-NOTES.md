# MusicDock Mini v2.0.2

文字の階層と読みやすさを重点的に改善したパッチです。

- Inter 4.1の可変フォントをローカル同梱。SIL Open Font License 1.1の原文をZIPに収録。フォント取得の外部通信なし。
- 通常サイズの曲名は18px / 580、アーティスト12.5px / 450、時刻11px / 500。字間と行間を一体で設計。
- ブランドを控えめなタイトルケースに変更し、過剰な字間を縮小。
- 長文は静的な省略表示と全文ツールチップ。小型・最小サイズでは段階的に縮小。
- 再生・同期アダプターと操作処理は維持。

Windowsのインストール済みChromeとChrome for Testingで本番レンダラーの描画を検証。実サービスでのユーザーChrome拡張機能受け入れ検証は別途必要です。

旧版の展開フォルダを最新版へ切り替え、拡張機能を再読み込みしYouTube Musicタブを更新してください。拡張機能詳細で2.0.2を確認してください。
