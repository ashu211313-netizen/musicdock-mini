# MusicDock Mini v2.0.1

公開v1.1.1の修正とローカルv2 UIを統合したパッチです。

- 再生時刻はYouTube Musicの再生バーから読み、古いvideoの時刻へフォールバックしません。
- 長さ・時刻が合う一意のメディアだけを操作対象とし、同一候補が複数ある場合はシーク・音量・ミュートを無効化します。
- 曲切り替え時はソースまたはメディアの更新イベントと安定期間を確認します。ドラッグ途中で曲が変わった場合のシークも拒否します。
- 内側の実buttonとdisabled状態、relative channelリンク、広告・inert状態を扱います。
- 黒基調のUI、統一SVG、中央再生ボタン、音量パネル、長文省略表示を統合しました。

実YouTube MusicのDOM構造と再生バー/メディアの丸め差は確認済みです。拡張機能を読み込んだユーザーのChromeでの実サービス受け入れ検証は未完了です。自動テストは生成WAVとテストDOMを使用します。Google / YouTube非公式のプレビュー版です。

旧版は拡張機能管理画面から削除または新しい展開フォルダへ切り替え、YouTube Musicタブを更新してください。拡張機能詳細で2.0.1と表示されることを確認してください。
