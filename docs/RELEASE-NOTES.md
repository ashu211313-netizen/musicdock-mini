# MusicDock Mini v2.0.3

同期待ちの遅延と極小表示を改善しました。

- 初期整合確認を600msから200ms、曲操作後の待機を750msから150msへ短縮。
- メディア/再生バーのイベントから50msに集約して更新。250msの復旧用ポーリングを併用。
- 短い時刻不一致で待機を最初からやり直さず、不一致中の操作は引き続き無効化。
- ジャケット更新を曲の識別子から分離。DOMに動画IDがある場合はアーティスト表記の更新でも同じ曲を維持。IDがない場合はアーティストを含め保守的に判定。
- リモートの極小グリッドレイアウトを統合。同期メッセージで時間・シークバーを隠さず、アーティスト欄に短く表示。
- 古いメディア、別動画、曖昧な候補への誤操作防止を維持。

テストDOM/生成WAVで回帰確認。ユーザー画像の実セッションを直接測定したものではなく、実YouTube Musicでの遅延解消は未認定です。旧版の展開フォルダを切り替えて拡張機能とYouTube Musicタブを再読み込みし、詳細の2.0.3を確認してください。
