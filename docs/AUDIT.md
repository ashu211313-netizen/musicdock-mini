# 初期監査と実装方針

ZIPの全テキスト3ファイルを読み、3アイコンを確認対象として保持。元のManifest V3、370×220のPiP、.title / .byline / #thumbnail、.previous-button / .play-pause-button / .next-button を再利用しました。

元実装: MAIN worldのグローバルフラグ、750msポーリング、3秒ごとのランチャー復元、HTML文字列の固定テンプレート、動画の先頭要素へのフォールバック、例外を握りつぶす再生処理。権限・独自通信なし。

課題: MAIN worldでの衝突リスク、再生対象の誤選択、無効操作の表示、未知の時間と0秒の混同、画像URLの検証不足、シーク可能区間の未確認、テスト・CI・配布設定なし。

対応: ISOLATED world、プレイヤー内mediaに限定、DOMアダプター分離、textContent/createElementでUI構築、画像ホスト検証と読み込み済み画像のCanvas描画、状態と操作可否の再取得、連打制限、PiP終了・親ページ終了時の後片付け。

元DOMを移動・削除せず、拡張機能独自のShadow DOMランチャーを追加します。通信不良はmedia.error/readyStateの範囲で表示し、ネットワーク監視や内部APIへの依存はしません。

初期サイズは追加操作と状態表示のため370×240へ変更。サイズ・位置の保存、テーマ切替は実装していません。ブラウザのPiP標準挙動を利用。

実YouTube Music DOMのライブ確認は未実施。セレクタは提供プロトタイプ由来で、モックテストによる回帰確認に限定されます。ログイン中の実タブ、Windows 10/11両環境、Edge、OS上での最前面・移動・リサイズの実機確認が必要です。

名称は仮称。一般Web検索で同名の明確な対象は確認できませんでしたが、商標データベースの調査・権利クリアランスは完了していません。
