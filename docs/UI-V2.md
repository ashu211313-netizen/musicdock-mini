## 文字見切れの解消

- .track/.meta/.title/.artistにmin-width:0を指定。.metaはflex:1 1 0%で残り幅に収めます。
- 曲名とアーティストにmax-width:100%、white-space:nowrap、overflow:hidden、text-overflow:ellipsisを指定。意図しない切断ではなく末尾「…」で省略し、title属性で全文を確認できます。
- 日本語の上端・下端が欠けないよう、固定高さを付けず、曲名の行高1.5、アーティスト1.6を確保。
- 年・アルバムをアーティスト欄から除外。複数のチャンネルリンクがある場合は「 / 」でまとめます。リンクがない場合は「•」「·」の前までを採用。
- 操作列を左右同幅＋中央トランスポートに分離。音量が曲情報や再生ボタンの位置を押しません。
- 低いウィンドウでは間隔とジャケットを縮めます。長いエラーはoverflow-wrap:anywhereで折り返し、必要な場合は縦スクロールで全文に到達できます。
- SVGの描画は固定のローカルpathを使用。曲名をHTMLとして挿入しません。

## 検証

- TypeScriptの型チェック、既存テストにアーティスト抽出テストを追加。
- 製品のmountPlayerをそのまま使うブラウザ用ハーネスで、長い日本語と空白なし英数字の曲名・アーティストを検証。
- 検証サイズ: 370×240 / 320×220 / 280×220 / 240×200 / 220×200 / 520×280。
- 各サイズで横/縦スクロールなし、文字のellipsis、再生ボタンの中心誤差1px以内、全ボタンが表示領域内、音量パネルが領域内であることを確認。
- 280×220では長いエラーの折り返しと、縦スクロールでの到達性も確認。
- Chromiumへの実拡張機能読み込みと実Document PiPによる既存操作テストを継続。テスト用DOM・生成無音WAVを使用し、実YouTube Musicとは区別します。
